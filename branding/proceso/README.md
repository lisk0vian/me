# Proceso

Cómo se llegó a la marca.

- **[`rondas/`](rondas/)**: las 12 rondas de conceptos de logo, en orden. Lo que se fue descartando:
  - el monograma "JA", que en español se lee como risa;
  - usar la A como marca;
  - los colores brillantes;
  - las "jj" repetidas.

  Al final el logo dejó de usar letras y pasó a ser un símbolo con identidad propia.
- **[`conceptos/`](conceptos/)**: los tres conceptos de la última ronda. Se eligió A, *Escalera*.
- **[`tipografia.png`](tipografia.png)**: las cuatro combinaciones de fuentes probadas. Se eligió B, Sora + JetBrains Mono.
- **[`estrategia/`](estrategia/)**: la estrategia de marca inicial (`brief.json`, `table.md`, tres sets A/B/C y `board.html`). Esa primera dirección se descartó.
- **[`scripts/`](scripts/)**: el código Python que genera el kit. Ver su README.
